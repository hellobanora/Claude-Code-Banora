# Handoff: picking up at the Banora work PC

Written 16 Nov 2026 on the Mac. Everything below is pushed to `main`.

## 1. Pull the changes

In the repo folder (Git Bash or PowerShell):

```bash
git status            # commit or stash anything local first
git pull
```

If `git pull` complains about `.claude/settings.local.json`, stash it, pull,
then `git stash pop`. If that conflicts, keep both sides' permission lines.

Then install the website's new packages (adds `google-auth-library`):

```bash
cd banora-website
npm install
npm run build         # should end with "Sitemap check passed"
```

## If something breaks

- **SEO email says Google auth failed:** rerun `node scripts/gbp-oauth-setup.mjs <client_secret.json>` from `banora-website` (Add secret in Google Cloud → Clients first, keep the WYw8 one), update `GOOGLE_OAUTH_REFRESH_TOKEN` in Vercel, redeploy.
- **Cron didn't run:** Vercel → Settings → Cron Jobs → Run, then check logs.
- **Routine failed:** https://claude.ai/code/routines → the routine → latest run.
